# Weather Dashboard 🌤️

A web-based weather dashboard that allows users to check current weather information for different locations.

This project demonstrates my practical learning of frontend development, JavaScript, and API integration.

## 🌐 Live Demo

[View Weather Dashboard](https://weather-dashboard-cpic.onrender.com)

## ✨ Features

- Search weather information by city.
- Display current temperature.
- Show weather conditions.
- Provide location-based weather information.

- ## 🛠️ Technologies Used

- HTML5 — Structure of the application
- CSS3 — Styling and layout
- JavaScript — Application logic and interactivity
- Weather API — Fetching weather information
